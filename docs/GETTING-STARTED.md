# 지금 시작하기 — 4개 채널 순서대로

요청하신 순서대로: **① 일본어 뉴스카드 인스타 → ② 네이버 블로그 → ③ 온라인 쇼핑몰 → ④ 유튜브 쇼츠(밈 자막 컴필레이션)**. 하나씩 오늘 바로 실행할 수 있는 체크리스트입니다. 순서대로 하나 끝내고 다음으로 넘어가도 되고, 동시에 진행해도 됩니다.

---

## ① 일본어 뉴스카드 인스타그램

- [ ] 인스타 계정을 **프로페셔널(비즈니스/크리에이터)** 계정으로 전환 (설정 > 계정 유형)
- [ ] Facebook 페이지 만들고 인스타 계정과 연결
- [ ] [Meta for Developers](https://developers.facebook.com)에서 앱 생성 → Instagram Graph API 권한 추가, 장기 액세스 토큰 발급 (`tools/instagram-publish/README.md` 1번 참고)
- [ ] 첫 소재 하나 정해서 뉴스카드 생성 테스트 (japna_issue 스타일: 어두운 배경 사진 + 카테고리 태그 + 강조 헤드라인 + 팩트, 일본어):
  ```bash
  cd tools/content-generator
  node generate-cardnews.mjs "다룰 뉴스/소재" --category "話題" --photo ./사진.jpg
  ```
- [ ] `.env`에 토큰 넣고 `tools/instagram-publish/publish.mjs`로 첫 발행 테스트
- [ ] 사진을 쓸 때는 저작권/초상권 확인 필수 (`tools/content-generator/README.md`의 "사진 사용 시 주의" 참고)

**2026년 인스타 알고리즘 핵심 (반드시 반영)**
- 좋아요보다 **저장·공유가 3~5배 더 강한 신호**입니다. 캡션에 "저장해두고 나중에 보세요" 같은 저장 유도 문구를 넣으세요.
- 게시 후 **첫 1시간 반응**이 그 게시물의 도달을 사실상 결정합니다. 팔로워가 활동하는 시간대(저녁 시간대 등)에 맞춰 발행하세요.
- 캡션 끝에 답하기 쉬운 질문을 넣어 댓글을 유도하세요 (댓글도 강한 신호).
- 광고 느낌 나는 콘텐츠보다 자연스러운 정보/스토리형 콘텐츠가 더 잘 노출됩니다.

## ② 네이버 블로그 (조회수 최우선)

**먼저 읽으세요 → [`docs/NAVER-BLOG-SEO.md`](NAVER-BLOG-SEO.md)** — 알고리즘 기준 상세 가이드입니다.

- [ ] 블로그 주제를 1~2개로 확정 (예: "일본 이슈/트렌드"로 인스타·쇼츠와 리서치 공유)
- [ ] 카테고리 구조 설계 (3~5개)
- [ ] 첫 글 작성:
  ```bash
  cd tools/content-generator
  node generate-blog.mjs "첫 블로그 주제"
  ```
- [ ] **AI 초안을 그대로 쓰지 말고**, 직접 경험/의견 1~2문단 + 직접 준비한 사진을 반드시 추가 (2026년 네이버는 AI가 뽑은 광고성 글을 하이퍼클로바X로 실시간 판별해서 노출에서 배제합니다 — 가장 중요한 원칙)
- [ ] 발행 후 통계(조회수, 유입 검색어) 확인하는 루틴 만들기
- [ ] 첫 주는 주 3~4회, 같은 주제로만 발행

## ③ 온라인 쇼핑몰 시작하기

아이템이 아직 정해지지 않았어도, **판매 인프라 준비는 미리 해둘 수 있습니다.**

### 3-1. 사업자 준비 (아이템 확정 전에도 가능)
- [ ] 홈택스에서 개인 사업자 등록 (업종코드 `525101` 전자상거래 소매업이 가장 일반적)
- [ ] 사업자등록증 발급 후 **통신판매업 신고** (구청/시청 방문 또는 정부24 온라인, 사업자등록증+신분증+입금계좌 사본 필요, 수수료 약 4,500원)

### 3-2. 스마트스토어 개설 (가장 빠르게 검증하는 채널)
- [ ] [네이버 스마트스토어센터](https://sell.smartstore.naver.com)에서 가입 → 사업자 선택 → 사업장 정보 입력
- [ ] 통신판매업 신고증 등 증빙서류 제출 → 심사(보통 1~2시간 내 승인)
- [ ] 첫 상품 1~2개 소량으로 등록 (`docs/PRODUCT-IDEAS.md` 아이디어 참고)

### 3-3. 아이템이 아직 없다면
`docs/PRODUCT-IDEAS.md`의 프레임워크대로, 인스타/블로그/쇼츠 콘텐츠에 대한 반응을 몇 주 쌓은 뒤 반응 좋은 소재를 기준으로 좁혀나가는 걸 권장합니다. 급하게 정하지 않아도 사업자 등록·스토어 개설은 지금 미리 끝내둘 수 있습니다.

## ④ 유튜브 쇼츠 자동화 (밈 자막 컴필레이션, simkoongzzal 스타일)

- [ ] [ffmpeg](https://ffmpeg.org) 설치
- [ ] 한국어 폰트 확인 (Noto Sans CJK, 나눔고딕 등 — 없으면 `apt install fonts-nanum` 등으로 설치)
- [ ] 첫 자막 생성:
  ```bash
  cd tools/youtube-shorts
  cp .env.example .env   # ANTHROPIC_API_KEY 있으면 자동 자막 생성
  node generate-script.mjs "첫 테마 (예: 안 웃을 수 없는 동물들)" --count 6
  ```
- [ ] 생성된 `script.json`의 `footage_hint`를 참고해서 영상 클립을 직접 준비 (직접 촬영 권장 — 저작권 안내는 `tools/youtube-shorts/README.md` 참고), `00.mp4`, `01.mp4` ... 이름으로 한 폴더에 모으기
- [ ] 영상 합성:
  ```bash
  node assemble-video.mjs --script output/.../script.json --footage ./footage --brand "@내채널"
  ```
- [ ] Google Cloud Console에서 OAuth 클라이언트 발급 → `tools/youtube-publish`로 첫 업로드 테스트 (처음엔 `--privacy private`로 비공개 테스트 업로드 권장)

## 공통 팁: 4개 채널을 하나의 루틴으로 묶기
매주 정해진 시간에 다음 순서로 작업하면 리서치를 4번 반복하지 않아도 됩니다.
1. 이번 주 소재 1개 정하기 (일본 트렌드/이슈 등)
2. 블로그 글로 깊이 있게 작성 (`generate-blog.mjs`)
3. 같은 소재를 카드뉴스로 요약 (`generate-cardnews.mjs`)
4. 랭킹 형식으로 바꿀 수 있으면 쇼츠 대본으로도 재가공 (`generate-script.mjs`)
5. 반응 좋은 소재는 온라인 스토어 아이템 후보로 기록
