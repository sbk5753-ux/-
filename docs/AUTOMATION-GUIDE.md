# 콘텐츠·커머스 자동화 마스터 가이드

카페 운영을 주업으로 하면서 **네이버 블로그 + 일본 카드뉴스 인스타그램 + 온라인 쇼핑몰**을 자동화된 수익 파이프라인으로 키워서, 궁극적으로 이 사업을 주업무로 전환하는 것을 목표로 합니다. 이 문서는 채널별로 "무엇을, 어떤 도구로, 어떤 순서로" 자동화할지 단계별로 정리한 실행 가이드입니다.

---

## 0. 전체 그림

```
[콘텐츠 기획] → [콘텐츠 제작(AI 보조)] → [발행] → [분석] → [재사용/최적화]
      │                  │                  │         │
      └── 키워드/트렌드    └── 글·이미지·번역    └── 채널별  └── 다음 기획에 반영
          리서치               자동 생성            발행 자동화
```

세 채널(블로그/인스타/쇼핑몰)은 서로 별개가 아니라 **하나의 콘텐츠를 재활용하는 파이프라인**으로 설계하는 것이 핵심입니다. 예: 블로그에 쓴 글 → 요약해서 카드뉴스로 재가공 → 쇼핑몰 상품 상세페이지/블로그 후기로 재활용.

자동화는 "완전 자동(사람 개입 없음)"과 "반자동(AI가 초안을 만들고 사람이 최종 검수 후 발행)" 두 단계로 나눠서 접근하세요. **처음엔 반자동으로 시작해서 검증된 것만 완전자동으로 승격**하는 게 계정 정지·품질 저하 리스크를 줄이는 현실적인 방법입니다.

---

## 1. 네이버 블로그 자동화

### 1-1. 현실적인 제약부터 이해하기
네이버는 개인 블로그에 대해 **공개적으로 안정적인 "자동 글 발행 API"를 제공하지 않습니다.** 과거 블로그 API가 있었지만 현재는 사실상 개인 개발자가 승인받기 어렵고, 매크로/브라우저 자동 로그인으로 발행하는 방식은 **네이버 이용약관 위반으로 계정 정지 리스크**가 있습니다. 따라서 권장 전략은 다음과 같습니다.

- **1단계(권장, 지금 바로 시작 가능): 콘텐츠 제작만 자동화, 발행은 수동**
  - 키워드 리서치 → AI로 초안 작성 → 이미지 생성 → 사람이 3~5분 검수 후 직접 붙여넣기 발행
  - 이 저장소의 `tools/content-generator`가 이 단계를 처리합니다 (아래 3장 참고)
- **2단계(선택, 리스크 인지 후 진행): 네이버 오픈 API 신청**
  - [네이버 개발자센터](https://developers.naver.com)에서 애플리케이션 등록 후 "검색", "블로그" 관련 API 사용 신청 (읽기 위주 API가 많고, 글쓰기 API는 승인 심사가 까다롭습니다)
  - 승인이 되면 OAuth2 토큰 발급 후 REST 호출로 발행 가능 — 승인 여부가 불확실하므로 1단계를 메인으로 두고 이건 보조 수단으로 취급하세요
- **하지 말아야 할 것**: 아이디/비번을 코드에 넣어 로그인 자동화, 여러 계정으로 동일/유사 콘텐츠 대량 발행(어뷰징 → 저품질/블랙블로그 판정)

### 1-2. SEO·주제 리서치 자동화
- **네이버 데이터랩**(datalab.naver.com): 검색어 트렌드 무료 확인
- **네이버 검색광고 키워드도구**: 월간 검색량, 경쟁 강도 확인 (무료 가입)
- 카페 사장님 입장에서 강점 있는 주제: 카페 창업/운영 노하우, 원두·음료 레시피, 상권 분석, 소상공인 자동화 경험담 — **본업 경험이 콘텐츠 소재로 직결**되므로 초반 신뢰도 확보에 유리합니다

### 1-3. 콘텐츠 생성 자동화
`tools/content-generator`의 `generate-blog.mjs`를 사용해 키워드만 입력하면:
1. 제목 후보 5개
2. 목차(H2/H3 구조)
3. 본문 초안(마크다운)
4. 태그 추천
5. 필요한 이미지 설명(직접 촬영/AI 이미지 생성용 프롬프트)

를 `/output/blog/` 폴더에 파일로 생성합니다. 이걸 검수 후 네이버 블로그 에디터에 붙여넣기만 하면 됩니다.

### 1-4. 발행 주기 관리 (자동 알림)
완전 자동 발행 대신, **"발행하세요" 알림을 자동화**하는 것은 안전하고 효과적입니다. GitHub Actions로 매일 정해진 시간에 콘텐츠 초안을 생성해두고, 알림을 받아 검수 후 발행하는 흐름을 `.github/workflows/`에 cron으로 구성할 수 있습니다 (원하시면 다음 단계로 추가해 드리겠습니다).

## 2. 인스타그램 (일본 카드뉴스) 자동화

인스타그램은 네이버와 달리 **Meta 공식 Graph API로 합법적인 자동 발행이 가능**합니다. Buffer, Later 같은 예약 발행 툴도 다 이 API를 씁니다.

### 2-1. 사전 준비 (최초 1회)
1. 인스타그램 계정을 **프로페셔널(비즈니스/크리에이터) 계정**으로 전환
2. Facebook 페이지와 인스타그램 계정 연결
3. [Meta for Developers](https://developers.facebook.com)에서 앱 생성 → `Instagram Graph API` 권한 추가
4. 장기 액세스 토큰(Long-lived Access Token) 발급 (60일, 갱신 로직 필요)
5. `Instagram Business Account ID` 확인

### 2-2. 카드뉴스 제작 자동화
- **원본(한국어) 콘텐츠 기획**: 블로그 글/트렌드에서 소재 추출
- **일본어 번역**: DeepL API (품질 우수, 저렴) 또는 Claude로 번역 + 현지화(직역이 아니라 일본 소비자 정서에 맞게 톤 조정 — 존댓말/캐주얼 체 선택 중요)
- **카드뉴스 이미지 생성**: 두 가지 방법
  - (A) 템플릿 기반: Canva API 또는 HTML/CSS 템플릿을 Puppeteer로 PNG 렌더링 (완전 자동, 디자인 일관성 좋음)
  - (B) AI 이미지 생성: 텍스트를 이미지 위에 얹는 배경/일러스트를 AI로 생성 후 텍스트 오버레이
- 이 저장소의 `tools/content-generator/generate-cardnews.mjs`가 (A) 방식의 뼈대를 제공합니다

### 2-3. 발행 자동화
`tools/instagram-publish/publish.mjs` 스크립트가 실제 Graph API를 호출해 캐러셀(여러 장 카드뉴스)을 발행합니다.
```bash
cd tools/instagram-publish
cp .env.example .env   # 토큰/계정ID 입력
npm install
node publish.mjs --images ./output/cardnews/2026-08-31 --caption "캡션.txt"
```
동작 원리: 이미지 각각을 `media` 컨테이너로 업로드 → `carousel` 컨테이너로 묶음 → `media_publish`로 최종 발행. (Graph API 특성상 이미지는 공개 URL이어야 하므로, 먼저 이미지 호스팅(예: GitHub Pages, S3, Cloudinary)에 업로드하는 단계가 필요합니다 — 스크립트에 업로드 훅이 있습니다.)

### 2-4. 예약 발행
GitHub Actions cron 또는 로컬 cron으로 `publish.mjs`를 매일 정해진 시간에 실행하면 완전 자동 예약 발행이 됩니다.

### 2-5. 일본 시장 특이사항 (중요)
- **경품표시법(景品表示法)**: 과장 광고, "최고", "1위" 같은 표현에 엄격 — 문구 검수 필수
- 협찬/광고 게시물은 `#PR` `#広告` 명시 필요 (스텔스 마케팅 규제 강화됨, 2023년부터)
- 일본 인스타 사용자는 **정보 밀도 높은 카드뉴스 + 정갈한 디자인**을 선호, 이모지 과다 사용은 신뢰도 하락 요인
- 해시태그는 일본어 대세 태그 + 니치 태그 혼합 (예: #カフェ好きな人と繋がりたい 같은 커뮤니티형 태그)

## 3. 온라인 쇼핑몰 자동화 로드맵

바로 자체 쇼핑몰(자사몰)을 코딩하는 것보다, **단계적으로 확장**하는 것을 권장합니다.

### 1단계 (0~3개월): 마켓플레이스로 빠르게 검증
- **네이버 스마트스토어** 또는 **쿠팡**: 카페 운영 노하우에서 나온 상품(원두, 굿즈, 레시피 키트 등)을 소량으로 먼저 팔아보고 반응 확인
- 블로그/인스타 콘텐츠로 유입 → 스마트스토어 링크로 전환, 이 흐름에서 **어떤 콘텐츠가 실제 구매로 이어지는지 데이터 축적**

### 2단계 (3~6개월): 자사몰 구축 + 콘텐츠 연동
반응이 검증되면 브랜드 자산(도메인, 고객 데이터, 마진)을 확보할 수 있는 자사몰로 확장합니다.
- **빠른 시작**: Cafe24, 고도몰 같은 국내 쇼핑몰 빌더 (무료/저비용, 결제·배송 연동 기본 제공)
- **커스터마이징 원할 때**: 이 저장소 `site/`에 있는 랜딩페이지를 확장해서 Next.js + 결제모듈(토스페이먼츠/아임포트) 조합의 자체 쇼핑몰로 발전 (원하시면 다음 단계로 코딩해 드립니다)
- 이 단계에서 **재고-주문-배송 자동화**: 스마트스토어/쿠팡/자사몰 재고를 하나의 스프레드시트나 간단한 DB로 동기화하는 스크립트 필요 (수작업 대비 오류·품절 리스크 크게 감소)

### 3단계 (6개월~): 운영 자동화
- 자동 리뷰 요청 메시지(구매 후 N일 뒤 발송)
- 재구매 유도 이메일/알림톡 자동화
- 블로그·인스타 콘텐츠에서 자동으로 상품 링크 삽입 (콘텐츠 → 커머스 전환 자동화)

## 4. 수익화 전략 정리

| 채널 | 초기 수익화 | 성장 후 수익화 |
|---|---|---|
| 네이버 블로그 | 애드포스트, 쿠팡파트너스 등 제휴마케팅 | 브랜드 협찬, 자사몰 유입 채널 |
| 인스타(일본) | 제휴링크(라쿠텐어필리에이트, Amazon아소시에이트 재팬) | 브랜드 PR, 자사 상품 판매, 일본向け 굿즈 |
| 온라인 쇼핑몰 | 소량 상품 직접 판매(마켓플레이스) | 자사몰 브랜드화, 정기구독/시즌 상품 |

핵심은 **블로그·인스타는 트래픽/신뢰 자산을 쌓는 채널, 쇼핑몰은 그 자산을 현금화하는 채널**이라는 역할 분담입니다.

## 5. 카페 운영 → 온라인 사업 전환 로드맵 (권장 타임라인)

이건 어디까지나 가이드이며, 실제 진행 속도에 맞춰 조정하세요.

- **1개월차**: 콘텐츠 생성 파이프라인 세팅(이 저장소 도구 사용), 주 3회 블로그 발행, 주 3회 카드뉴스 발행 습관화. 카페 매출은 그대로 유지.
- **2~3개월차**: 인스타 발행 자동화(Graph API) 완성, 데이터 쌓이는 대로 어떤 소재가 반응 좋은지 분석. 스마트스토어로 첫 상품 테스트 판매.
- **4~6개월차**: 온라인 채널에서 나오는 순수익이 카페 순이익의 일정 비율(예: 20~30%)을 넘으면 자사몰 구축 착수, 카페 근무 시간 일부를 온라인 사업으로 재배치 검토.
- **6개월 이후**: 온라인 채널 수익이 카페 수익을 안정적으로 넘어서면(최소 3개월 연속) 본업 전환 여부 결정. 이 시점까지는 **카페를 리스크 헤지 수단으로 유지**하는 걸 권장합니다 — 온라인 사업은 초기 변동성이 크기 때문입니다.

## 7. 주의사항 요약
- 네이버/인스타 모두 **어뷰징(대량 도배, 매크로 로그인)은 계정 정지로 직결** — 항상 공식 API 또는 반자동(사람 검수) 방식 사용
- 이미지·폰트 저작권 확인 (상업적 이용 가능한 소스만 사용: 눈누, Unsplash, 직접 생성 등)
- 협찬/광고 콘텐츠는 국내(표시광고법)·일본(경품표시법) 모두 광고 표시 의무 있음
- 개인정보(고객 연락처 등) 다룰 때는 최소 수집 원칙 준수
