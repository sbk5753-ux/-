# 콘텐츠·커머스 자동화 마스터 가이드

**네이버 블로그 / 일본어 뉴스카드 인스타그램 / 유튜브 쇼츠(밈 자막 컴필레이션) / 온라인 사업(아이템 미정)** 네 가지 축을 자동화된 수익 파이프라인으로 만드는 것이 목표입니다. 이 문서는 채널별로 "무엇을, 어떤 도구로, 어떤 순서로" 자동화할지 단계별로 정리한 실행 가이드입니다.

> 본업(카페 등)과는 별개의 독립 프로젝트로 운영합니다. 콘텐츠 소재는 특정 오프라인 업종에 종속되지 않고, 각 채널의 성격(일본 뉴스/이슈, 흥미 위주 컴필레이션 등)에 맞춰 자유롭게 선정합니다.

---

## 0. 전체 그림

```
[콘텐츠 기획] → [콘텐츠 제작(AI 보조)] → [발행] → [분석] → [재사용/최적화]
      │                  │                  │         │
      └── 키워드/트렌드    └── 글·이미지·영상·번역  └── 채널별  └── 다음 기획에 반영
          리서치               자동 생성            발행 자동화
```

네 채널은 서로 별개가 아니라 **하나의 리서치·소재를 재활용하는 파이프라인**으로 설계하는 것이 핵심입니다. 예: 일본 이슈를 리서치하다 발견한 소재 → 블로그 글(깊이 있는 정보) / 뉴스카드(요약+비주얼)로 재가공하고, 흥미 위주 소재는 쇼츠(밈 자막 컴필레이션)로 별도 제작.

자동화는 "완전 자동(사람 개입 없음)"과 "반자동(AI가 초안을 만들고 사람이 최종 검수 후 발행)" 두 단계로 나눠서 접근하세요. **처음엔 반자동으로 시작해서 검증된 것만 완전자동으로 승격**하는 게 계정 정지·수익화 박탈 리스크를 줄이는 현실적인 방법입니다.

## 1. 네이버 블로그 자동화

> **조회수를 올리는 게 목표라면 → [`docs/NAVER-BLOG-SEO.md`](NAVER-BLOG-SEO.md)를 꼭 먼저 읽으세요.** C-Rank/D.I.A.+ 알고리즘 기준 상세 체크리스트가 있습니다.

### 1-1. 현실적인 제약부터 이해하기
네이버는 개인 블로그에 대해 **공개적으로 안정적인 "자동 글 발행 API"를 제공하지 않습니다.** 매크로/브라우저 자동 로그인으로 발행하는 방식은 **네이버 이용약관 위반으로 계정 정지 리스크**가 있습니다. 권장 전략은 다음과 같습니다.

- **1단계(권장, 지금 바로 시작 가능): 콘텐츠 제작만 자동화, 발행은 수동**
  - 키워드 리서치 → AI로 초안 작성 → 이미지 생성 → 사람이 3~5분 검수 후 직접 붙여넣기 발행
  - 이 저장소의 `tools/content-generator`가 이 단계를 처리합니다
- **2단계(선택, 승인 불확실): 네이버 오픈 API 신청**
  - `tools/naver-blog/README.md` 참고

### 1-2. 주제 리서치 자동화
- **네이버 데이터랩**(datalab.naver.com): 검색어 트렌드 무료 확인
- **네이버 검색광고 키워드도구**: 월간 검색량, 경쟁 강도 확인
- 다른 채널(일본 이슈 뉴스카드, 유튜브 쇼츠)에서 리서치한 소재를 한국 독자용으로 심화·재가공하면 리서치 비용을 채널 간에 나눠 쓸 수 있습니다

### 1-3. 콘텐츠 생성 자동화
`tools/content-generator/generate-blog.mjs`에 키워드만 입력하면 제목 후보, 목차, 본문 초안, 태그, 이미지 가이드를 `/output/blog/`에 생성합니다. 검수 후 네이버 블로그 에디터에 붙여넣어 발행하세요.

## 2. 인스타그램 (일본 이슈 카드뉴스) 자동화

인스타그램은 **Meta 공식 Graph API로 합법적인 자동 발행이 가능**합니다.

### 2-1. 사전 준비 (최초 1회)
1. 인스타그램 계정을 **프로페셔널(비즈니스/크리에이터) 계정**으로 전환
2. Facebook 페이지와 인스타그램 계정 연결
3. Meta for Developers에서 앱 생성 → `Instagram Graph API` 권한 추가
4. 장기 액세스 토큰(60일) 발급, Business Account ID 확인

### 2-2. 콘텐츠 포맷 (japna_issue 실제 운영 스타일)
게시물 1개 = 뉴스/이슈 1건인 **단일 이미지 뉴스카드**입니다 (여러 장 넘기는 캐러셀이 아님). 어두운 배경 사진 위에 빨간 카테고리 태그(`スキャンダル` `天気` `芸能` `災害` `話題` 등) + 빨간 강조 헤드라인 + 팩트 불릿 3~4개, 전부 **일본어**로 구성합니다. 다루는 카테고리는 연예 스캔들, 날씨/재난, K팝 등 한일 크로스오버 뉴스까지 폭넓습니다.

- **소재 리서치**: 일본 뉴스/SNS 화제, 연예 이슈, 날씨/재난 속보 등에서 소재 발굴
- **카드 생성**: `tools/content-generator/generate-cardnews.mjs "소재" --category "카테고리" --photo <사진>`이 카테고리/헤드라인/팩트를 일본어로 생성하고 PNG까지 렌더링
- **사진 사용 주의**: 연예인/뉴스 인물 사진을 무단 캡처하면 저작권·초상권 문제가 생길 수 있습니다. 공식 배포 이미지, 라이선스 구매 이미지를 쓰거나, 인물 없는 소재(날씨 등)는 직접 만든 그래픽으로 대체하세요 (`tools/content-generator/README.md` 참고)
- 발행 전 사실관계 검증 필수 (이슈/뉴스 소재는 오보 리스크가 있으므로 출처 확인)

### 2-3. 발행 자동화
`tools/instagram-publish/publish.mjs`가 Graph API로 이미지를 자동 발행합니다 (단일 이미지 포스트 — 캐러셀이 필요할 땐 여러 이미지를 넘기면 자동으로 캐러셀 처리됨). 자세한 사용법은 해당 폴더 README 참고.

### 2-4. 2026년 노출 알고리즘 핵심
- **저장·공유가 좋아요보다 3~5배 강한 신호**입니다. 캡션에 저장을 유도하는 문구를 넣으세요.
- **게시 직후 1시간 반응이 도달을 사실상 결정**합니다. 타겟 독자(일본 사용자)가 활동하는 시간대에 맞춰 발행하세요.
- 댓글도 강한 신호이므로 캡션 끝에 답하기 쉬운 질문을 넣으세요.
- 체류 시간이 핵심 랭킹 시그널이므로, 카드 수를 늘려 끝까지 넘겨보게 만드는 구성이 유리합니다.

### 2-5. 주의사항
- 뉴스/이슈성 콘텐츠는 **사실 왜곡·자극적 제목(낚시성)**이 계정 신뢰도를 크게 깎습니다. 원 출처를 명시하고, 의견과 사실을 구분해서 전달하세요.
- 협찬/광고 게시물은 광고 표시 필수 (한국 표시광고법, 일본 경품표시법)

## 3. 유튜브 쇼츠 (밈 자막 컴필레이션) 자동화

레퍼런스로 삼은 채널(simkoongzzal 스타일)처럼, **실제 영상 클립 + 굵은 외곽선 밈 자막(한국어)** 으로 구성된 테마별 컴필레이션 쇼츠를 만드는 파이프라인입니다. 나레이션은 없고, 자막이 콘텐츠의 전부입니다.

### 3-1. 제작 파이프라인
```
테마 선정 → 클립별 자막 생성(AI) → 영상 클립 소싱(직접) → 자막·워터마크 합성(ffmpeg) → 업로드
```
1. **자막 생성**: `tools/youtube-shorts/generate-script.mjs`가 테마만 넣으면 클립별 밈 자막 + 어떤 영상이 필요한지(footage_hint)를 JSON으로 만듭니다.
2. **영상 클립 소싱**: footage_hint를 참고해 실제 영상 클립을 직접 준비합니다 (직접 촬영이 가장 안전 — 저작권 안내는 `tools/youtube-shorts/README.md` 참고).
3. **영상 합성**: `tools/youtube-shorts/assemble-video.mjs`가 ffmpeg로 클립마다 굵은 외곽선 자막을 얹고, 좌하단에 마스코트/채널 워터마크를 붙여 세로형(1080x1920) 영상을 만듭니다.
4. **업로드**: `tools/youtube-publish/publish.mjs`가 YouTube Data API v3(공식)로 업로드/예약 발행합니다.

나레이션이 필요한 랭킹형(TOP5 카운트다운) 콘텐츠를 별도로 만들고 싶다면 `tools/youtube-shorts/tts-voicevox.mjs`(일본어 TTS, VOICEVOX)로 선택적으로 확장할 수 있지만, 기본 파이프라인은 이 자막 컴필레이션 형식입니다.

### 3-2. 반드시 알아야 할 2026년 유튜브 수익화 정책 (중요)
2026년 유튜브는 "반복 콘텐츠(repetitious content)" 정책을 **"비authentic 콘텐츠(inauthentic content)"** 정책으로 확대·강화했고, 2026년 1월에는 이 정책으로 대형 채널들이 대거 수익화 박탈되는 사례가 있었습니다. 핵심 기준은 다음과 같습니다.

- **금지되는 것**: 동일 템플릿의 TTS+슬라이드쇼를 변주 없이 반복, 창작자의 독자적 관점·해설이 전혀 없는 대량생산형 콘텐츠, AI가 만들었다는 걸 숨기고 정형화된 템플릿만 반복하는 콘텐츠
- **괜찮은 것**: AI를 쓰더라도 **창작자만의 코멘터리, 편집 스타일, 오리지널 관점**이 들어간 콘텐츠. 매 영상마다 실질적으로 다른 가치(정보·재미·통찰)를 제공하면 문제없음

**밈 자막 컴필레이션 형식은 이 기준에서 상대적으로 안전한 편입니다** — TTS 슬라이드쇼가 아니라 직접 소싱한 영상 + 매번 새로 쓰는 자막이 핵심이기 때문입니다. 다만 아래는 꼭 지키세요.
- 자막을 AI 초안 그대로 쓰지 말고, 실제로 웃긴/재치있는 표현으로 다듬기
- 영상 클립은 직접 촬영하거나 출처가 명확한 소스만 사용 (`tools/youtube-shorts/README.md`의 저작권 안내 참고)
- 매 영상 소재를 겹치지 않게 다양화 (완전히 똑같은 패턴 반복은 피하기)

### 3-3. 업로드 전략
- 주 3~5회 업로드가 채널 성장에 유리 (알고리즘 노출 관련 데이터)
- 시청 완료율 70% 이상을 목표로, 영상 도입부(첫 클립)에 가장 임팩트 있는 자막/장면을 배치
- 페이스리스(얼굴 없는) 포맷 자체는 시청 유지율 측면에서 불리하지 않으니, 퀄리티(자막 가독성, 클립 리듬감, 마스코트 워터마크로 브랜드 일관성 유지)에 집중

## 4. 온라인 사업 (아이템 미정)

아이템이 아직 정해지지 않았어도 **판매 인프라 준비는 미리 할 수 있습니다.**

### 4-1. 사업자·판매 인프라 준비 (지금 바로 가능)
1. 홈택스에서 개인 사업자 등록 (업종코드 `525101` 전자상거래 소매업)
2. 사업자등록증 발급 후 **통신판매업 신고** (구청/정부24, 사업자등록증+신분증+입금계좌 사본, 수수료 약 4,500원)
3. [네이버 스마트스토어센터](https://sell.smartstore.naver.com)에서 가입 → 사업자 정보 입력 → 증빙서류 제출 → 심사(보통 1~2시간 내 승인)

자세한 절차는 [`docs/GETTING-STARTED.md`](GETTING-STARTED.md)의 "③ 온라인 쇼핑몰 시작하기" 참고.

### 4-2. 아이템 좁혀나가기
1. **콘텐츠 채널을 리서치 엔진으로 활용**: 일본 이슈 뉴스카드와 유튜브 쇼츠를 운영하면서 반응이 특히 좋은 소재/카테고리를 데이터로 축적 → 그 카테고리에서 파생 가능한 상품/서비스를 역으로 도출
2. **디지털 상품 우선 검토**: 초기 재고·물류 부담이 없는 디지털 상품(전자책, 정보성 PDF, 유료 뉴스레터, 템플릿, 프리미엄 콘텐츠 멤버십 등)부터 검증 후, 반응 좋으면 실물 상품으로 확장
3. **`docs/PRODUCT-IDEAS.md`** 에 트렌드 기반 아이디어와 검증 프로세스를 정리해 두었습니다. 방향이 좁혀지면 요청해주시면 상세 기획서를 만들어 드립니다.

| 채널 | 초기 수익화 | 성장 후 수익화 |

| 네이버 블로그 | 애드포스트, 제휴마케팅(쿠팡파트너스 등) | 브랜드 협찬, 자체 채널 유입원 |

## 7. 주의사항 요약
- 네이버/인스타/유튜브 모두 **어뷰징(대량 도배, 매크로 로그인, 정책 위반 반복 콘텐츠)은 계정 정지·수익화 박탈로 직결** — 항상 공식 API 또는 반자동(사람 검수) 방식 사용
- 이미지·영상·폰트 저작권 확인 (인스타 뉴스카드의 인물 사진은 초상권도 주의, 쇼츠 영상 클립은 직접 촬영 우선, 스톡 소스는 라이선스 확인)
- 뉴스/이슈성 콘텐츠는 사실관계 검증, 협찬/광고 콘텐츠는 광고 표시 의무 준수
- 유튜브는 2026년 "비authentic 콘텐츠" 정책을 반드시 숙지 (3장 참고)
