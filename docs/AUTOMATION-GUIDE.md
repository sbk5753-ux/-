# 콘텐츠·커머스 자동화 마스터 가이드

**네이버 블로그 / 일본 카드뉴스 인스타그램 / 일본 랭킹형 유튜브 쇼츠 / 온라인 사업(아이템 미정)** 네 가지 축을 자동화된 수익 파이프라인으로 만드는 것이 목표입니다. 이 문서는 채널별로 "무엇을, 어떤 도구로, 어떤 순서로" 자동화할지 단계별로 정리한 실행 가이드입니다.

> 본업(카페 등)과는 별개의 독립 프로젝트로 운영합니다. 콘텐츠 소재는 특정 오프라인 업종에 종속되지 않고, 각 채널의 성격(일본 트렌드/이슈, 랭킹형 흥미 콘텐츠 등)에 맞춰 자유롭게 선정합니다.

---

## 0. 전체 그림

```
[콘텐츠 기획] → [콘텐츠 제작(AI 보조)] → [발행] → [분석] → [재사용/최적화]
      │                  │                  │         │
      └── 키워드/트렌드    └── 글·이미지·영상·번역  └── 채널별  └── 다음 기획에 반영
          리서치               자동 생성            발행 자동화
```

네 채널은 서로 별개가 아니라 **하나의 리서치·소재를 재활용하는 파이프라인**으로 설계하는 것이 핵심입니다. 예: 일본 이슈를 리서치하다 발견한 소재 → 블로그 글(깊이 있는 정보) / 카드뉴스(요약+비주얼) / 쇼츠(랭킹·훅 중심)로 동시에 재가공.

자동화는 "완전 자동(사람 개입 없음)"과 "반자동(AI가 초안을 만들고 사람이 최종 검수 후 발행)" 두 단계로 나눠서 접근하세요. **처음엔 반자동으로 시작해서 검증된 것만 완전자동으로 승격**하는 게 계정 정지·수익화 박탈 리스크를 줄이는 현실적인 방법입니다.

## 1. 네이버 블로그 자동화

### 1-1. 현실적인 제약부터 이해하기
네이버는 개인 블로그에 대해 **공개적으로 안정적인 "자동 글 발행 API"를 제공하지 않습니다.** 매크로/브라우저 자동 로그인으로 발행하는 방식은 **네이버 이용약관 위반으로 계정 정지 리스크**가 있습니다. 권장 전략은 다음과 같습니다.

- **1단계(권장, 지금 바로 시작 가능): 콘텐츠 제작만 자동화, 발행은 수동**
  - 키워드 리서치 → AI로 초안 작성 → 이미지 생성 → 사람이 3~5분 검수 후 직접 붙여넣기 발행
  - 이 저장소의 `tools/content-generator`가 이 단계를 처리합니다
- **2단계(선택, 승인 불확실): 네이버 오픈 API 신청**
  - `tools/naver-blog/README.md` 참고

### 1-2. 주제 리서치 자동화
- **네이버 데이터랩**(datalab.naver.com): 검색어 트렌드 무료 확인
- **네이버 검색광고 키워드도구**: 월간 검색량, 경쟁 강도 확인
- 다른 채널(일본 이슈 카드뉴스, 랭킹 쇼츠)에서 리서치한 소재를 한국 독자용으로 심화·재가공하면 리서치 비용을 채널 간에 나눠 쓸 수 있습니다

### 1-3. 콘텐츠 생성 자동화
`tools/content-generator/generate-blog.mjs`에 키워드만 입력하면 제목 후보, 목차, 본문 초안, 태그, 이미지 가이드를 `/output/blog/`에 생성합니다. 검수 후 네이버 블로그 에디터에 붙여넣어 발행하세요.

## 2. 인스타그램 (일본 이슈 카드뉴스) 자동화

인스타그램은 **Meta 공식 Graph API로 합법적인 자동 발행이 가능**합니다.

### 2-1. 사전 준비 (최초 1회)
1. 인스타그램 계정을 **프로페셔널(비즈니스/크리에이터) 계정**으로 전환
2. Facebook 페이지와 인스타그램 계정 연결
3. Meta for Developers에서 앱 생성 → `Instagram Graph API` 권한 추가
4. 장기 액세스 토큰(60일) 발급, Business Account ID 확인

### 2-2. 카드뉴스 제작 자동화
- **소재 리서치**: 일본 뉴스/트렌드(SNS 화제, 화제 상품, 사회 이슈 등)에서 소재 발굴
- **카드뉴스 카피**: `tools/content-generator/generate-cardnews.mjs`가 AI로 카드별 카피 초안(일본어 또는 한국어, 타겟에 맞춰 선택)을 생성하고 PNG까지 렌더링
- 발행 전 사실관계 검증 필수 (이슈/뉴스 소재는 오보 리스크가 있으므로 출처 확인)

### 2-3. 발행 자동화
`tools/instagram-publish/publish.mjs`가 Graph API로 캐러셀을 자동 발행합니다. 자세한 사용법은 해당 폴더 README 참고.

### 2-4. 주의사항
- 뉴스/이슈성 콘텐츠는 **사실 왜곡·자극적 제목(낚시성)**이 계정 신뢰도를 크게 깎습니다. 원 출처를 명시하고, 의견과 사실을 구분해서 전달하세요.
- 협찬/광고 게시물은 광고 표시 필수 (한국 표시광고법, 일본 경품표시법)

## 3. 유튜브 쇼츠 (일본 랭킹 콘텐츠) 자동화

레퍼런스로 삼은 채널(@doubutsu_urabanashi 스타일)처럼, **"TOP 5" 같은 랭킹/카운트다운 형식의 일본어 쇼츠**를 만드는 파이프라인입니다.

### 3-1. 제작 파이프라인
```
주제 선정 → 대본 생성(AI) → 일본어 내레이션(TTS) → 배경 영상/이미지 → 자막 합성 → 업로드
```
1. **대본 생성**: `tools/youtube-shorts/generate-script.mjs`가 주제만 넣으면 훅(오프닝 3초) + 랭킹 5개 항목 + 아웃트로(구독 유도)로 구성된 JSON 대본을 만듭니다.
2. **일본어 내레이션**: **VOICEVOX**(무료, 오픈소스, 상업적 이용 가능 — 캐릭터별 이용 규약만 준수) 로컬 엔진을 띄운 뒤 `tools/youtube-shorts/tts-voicevox.mjs`로 대본을 음성으로 변환합니다.
3. **영상 합성**: `tools/youtube-shorts/assemble-video.mjs`가 ffmpeg로 나레이션 길이에 맞춰 세로형(1080x1920) 영상을 만듭니다. 기본값은 그라데이션 배경 + 큰 자막(저작권 이슈 없음)이며, 저작권 프리 소스(Pexels, Pixabay, Coverr 등)나 직접 촬영/생성한 이미지·영상으로 배경을 교체하면 퀄리티를 높일 수 있습니다.
4. **업로드**: `tools/youtube-publish/publish.mjs`가 YouTube Data API v3(공식)로 업로드/예약 발행합니다.

### 3-2. 반드시 알아야 할 2026년 유튜브 수익화 정책 (중요)
2026년 유튜브는 "반복 콘텐츠(repetitious content)" 정책을 **"비authentic 콘텐츠(inauthentic content)"** 정책으로 확대·강화했고, 2026년 1월에는 이 정책으로 대형 채널들이 대거 수익화 박탈되는 사례가 있었습니다. 핵심 기준은 다음과 같습니다.

- **금지되는 것**: 동일 템플릿의 TTS+슬라이드쇼를 변주 없이 반복, 창작자의 독자적 관점·해설이 전혀 없는 대량생산형 콘텐츠, AI가 만들었다는 걸 숨기고 정형화된 템플릿만 반복하는 콘텐츠
- **괜찮은 것**: AI/TTS를 쓰더라도 **창작자만의 코멘터리, 편집 스타일, 오리지널 관점**이 들어간 콘텐츠. AI 활용 사실을 투명하게 공개하고, 매 영상마다 실질적으로 다른 가치(정보·재미·통찰)를 제공하면 문제없음

**따라서 이 저장소의 자동화 도구는 "초안/베이스"까지만 자동화하는 용도로 쓰고, 다음을 반드시 사람이 더해야 합니다.**
- 훅/아웃트로 멘트에 채널만의 말투·캐릭터 부여
- 랭킹 항목 선정 기준이나 코멘트에 실제 리서치/의견 추가
- AI 음성·생성 콘텐츠 사용 사실을 채널 정보나 설명란에 고지 (유튜브 정책상 요구되는 경우 있음)

### 3-3. 업로드 전략
- 주 3~5회 업로드가 채널 성장에 유리 (알고리즘 노출 관련 데이터)
- 시청 완료율 70% 이상을 목표로 훅(첫 3초)과 랭킹 순서(궁금증 유발을 위해 낮은 순위→1위 순으로 카운트다운)를 설계
- 페이스리스(얼굴 없는) 포맷 자체는 시청 유지율 측면에서 불리하지 않으니, 퀄리티(자막 가독성, 리듬감 있는 편집)에 집중

## 4. 온라인 사업 (아이템 미정)

아직 구체적인 아이템/주제를 정하지 못한 상태입니다. 아래 방식으로 좁혀나가는 것을 권장합니다.

1. **콘텐츠 채널을 리서치 엔진으로 활용**: 일본 이슈 카드뉴스와 랭킹 쇼츠를 운영하면서 반응이 특히 좋은 소재/카테고리를 데이터로 축적 → 그 카테고리에서 파생 가능한 상품/서비스를 역으로 도출
2. **디지털 상품 우선 검토**: 초기 재고·물류 부담이 없는 디지털 상품(전자책, 정보성 PDF, 유료 뉴스레터, 템플릿, 프리미엄 콘텐츠 멤버십 등)부터 검증 후, 반응 좋으면 실물 상품으로 확장
3. **`docs/PRODUCT-IDEAS.md`** 에 트렌드 기반 아이디어와 검증 프로세스를 정리해 두었습니다. 방향이 좁혀지면 요청해주시면 상세 기획서를 만들어 드립니다.

## 5. 수익화 전략 정리

| 채널 | 초기 수익화 | 성장 후 수익화 |
|---|---|---|
| 네이버 블로그 | 애드포스트, 제휴마케팅(쿠팡파트너스 등) | 브랜드 협찬, 자체 채널 유입원 |
| 인스타(일본 이슈) | 제휴링크(라쿠텐어필리에이트, Amazonアソシエイト) | 브랜드 PR, 자체 상품/디지털 콘텐츠 판매 |
| 유튜브 쇼츠(일본 랭킹) | YouTube Partner Program 광고 수익 (조건 충족 시) | 스폰서십, 자체 상품, 멤버십 |
| 온라인 사업 | (아이템 확정 후 결정) | (아이템 확정 후 결정) |

**세 콘텐츠 채널(블로그/인스타/쇼츠)은 트래픽·신뢰·팬덤 자산을 쌓는 채널, 온라인 사업은 그 자산을 현금화하는 채널**이라는 역할 분담으로 설계하세요.

## 7. 주의사항 요약
- 네이버/인스타/유튜브 모두 **어뷰징(대량 도배, 매크로 로그인, 정책 위반 반복 콘텐츠)은 계정 정지·수익화 박탈로 직결** — 항상 공식 API 또는 반자동(사람 검수) 방식 사용
- 이미지·영상·폰트·음성 저작권 확인 (VOICEVOX는 캐릭터별 이용 규약 준수, 스톡 소스는 라이선스 확인)
- 뉴스/이슈성 콘텐츠는 사실관계 검증, 협찬/광고 콘텐츠는 광고 표시 의무 준수
- 유튜브는 2026년 "비authentic 콘텐츠" 정책을 반드시 숙지 (3장 참고)
