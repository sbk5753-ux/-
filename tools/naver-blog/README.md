# naver-blog

네이버 블로그는 인스타그램과 달리 **개인 개발자가 안정적으로 쓸 수 있는 공식 "글쓰기" API가 없습니다.** 이 폴더는 그 현실을 반영해서 두 가지 경로를 제공합니다.

## 권장: 반자동화 (지금 바로 가능, 계정 정지 리스크 없음)
1. `tools/content-generator/generate-blog.mjs`로 초안 생성
2. 초안을 3~5분 검수/수정
3. 네이버 블로그 에디터에 직접 붙여넣어 발행

이 흐름이 **가장 안전하고 결과물 품질도 높습니다.** "자동화"의 핵심은 발행 클릭 자체가 아니라, 그 전 단계인 리서치·초안 작성 시간을 없애는 것이라고 생각하시면 됩니다.

## 선택: 네이버 오픈 API 신청 (승인 불확실, 참고용)
1. https://developers.naver.com 에서 애플리케이션 등록
2. "네이버 로그인" API로 사용자 OAuth2 인증 연동
3. 블로그 관련 API 사용 신청 (검색 API는 즉시 가능하나, **글쓰기용 API는 별도 승인 절차가 있고 개인 블로거에게는 승인이 나지 않는 경우가 많습니다** — 신청 전에 이 부분을 감안하세요)
4. 승인되면 발급받은 액세스 토큰으로 REST 호출

`post.mjs`는 승인을 받았다는 가정 하에 쓸 수 있는 **실험적** 스크립트입니다. 실제 엔드포인트/파라미터는 승인 시 네이버가 안내하는 문서에 맞춰 조정이 필요합니다 (공개 스펙이 계정마다 다를 수 있음).

## 하지 마세요
- 아이디/비밀번호로 로그인 자동화 (매크로/헤드리스 브라우저) → 네이버 이용약관 위반, 계정 정지 사유
- 여러 블로그/부계정으로 유사 콘텐츠 대량 발행 → 저품질 블로그로 분류되어 검색 노출 저하
